# Even support site

The public Privacy Policy, Terms of Use and Support pages for the Even app,
served by GitHub Pages. Plain HTML and CSS: no build step, no scripts, no
trackers or analytics. Fonts are served from this repo (SIL Open Font
License, see `assets/fonts/`).

- `index.html` – Support
- `privacy/index.html` – Privacy Policy
- `terms/index.html` – Terms of Use

When the app starts collecting something new (for example crash reports),
update the Privacy Policy and its date before that app version ships.
